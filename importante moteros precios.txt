Instrucciones para Revertir Ocultamiento de Precios
Este documento guarda los fragmentos de código originales por si se decide volver a mostrar los precios al público.

1. Eliminar CSS de Ocultamiento
En 
catalogo.html
 y 
index.html
, eliminar los bloques <style> que contienen:

/* OCULTAR PRECIOS TEMPORALMENTE (Solicitud Admin) */
.producto-precio, .precio, .current-price, ... { display: none !important; }
2. Restaurar Filtros en 
catalogo.html
Descomentar el bloque <select id="filtroPrecio">...</select>.

3. Restaurar Lógica de WhatsApp en 
js/catalogo.js
Buscar la función 
enviarPedidoWhatsApp
 y restaurar la construcción del mensaje:

/* CÓDIGO ORIGINAL (CON PRECIOS) */
carrito.forEach(item => {
    const descInfo = item.descuento ? ` (Dto. ${item.descuento}%)` : '';
    const varianteInfo = item.variante ? ` [${item.variante}]` : '';
    // LÍNEA CON PRECIO:
    mensaje += `• ${item.cantidad} x ${item.nombre}${varianteInfo}${descInfo}\n  ${item.marca}\n  $${parseInt(item.precio).toLocaleString('es-CO')} c/u\n\n`;
});
const total = carrito.reduce((s, item) => s + item.precio * item.cantidad, 0);
mensaje += `*Total estimado: $${total.toLocaleString('es-CO')}*\n\n¡Gracias! 🙌`;
4. Restaurar Lógica de WhatsApp en 
js/index.js
Buscar la función 
enviarPedidoWhatsApp
 y restaurar los detalles de precios y resumen:

/* CÓDIGO ORIGINAL (CON PRECIOS Y DESCUENTOS) */
carrito.forEach((item, i) => {
    // ... (código previo igual)
    mensaje += `   Cant: ${item.cantidad}\n`;
    // BLOQUE ELIMINADO:
    if (item.descuento > 0 || esCombo) {
        mensaje += `   P.Original: ~$${formatearPrecio(item.precioOriginal)}~\n`;
        mensaje += `   ${iconEtiqueta} *${item.promocion}* (-${item.descuento}%)\n`;
        mensaje += `   *P.Final: $${formatearPrecio(item.precioFinal)}*\n`;
    } else {
        mensaje += `   Precio: $${formatearPrecio(item.precioFinal)}\n`;
    }
    mensaje += `   Subtotal: *$${formatearPrecio(subFinal)}*\n\n`;
});
mensaje += `━━━━━━━━━━━━━━━━━━━━━━━━\n`;
// RESUMEN ELIMINADO:
mensaje += `📋 *RESUMEN*\n\n`;
mensaje += `   Subtotal: $${formatearPrecio(subtotal)}\n`;
if (totalDescuentos > 0) {
    mensaje += `   🎉 Descuentos: -$${formatearPrecio(totalDescuentos)}\n`;
}
mensaje += `\n   💰 *TOTAL: $${formatearPrecio(totalFinal)}*\n`;
mensaje += `━━━━━━━━━━━━━━━━━━━━━━━━\n\n`;
mensaje += `¡Gracias! 🙌`;
5. Limpieza JS (Opcional)
En 
js/catalogo.js
, se puede eliminar el <span> extra añadido en el render del carrito (.precio-carrito-ocultar), aunque no hace daño dejarlo.
